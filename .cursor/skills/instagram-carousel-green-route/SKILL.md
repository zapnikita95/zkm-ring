## Как делать пиздатые карусели (канон 2025–26)

Источники практики: Adpicto carousel 2026, Creatorflow carousel guide, SCRL seamless workflows, Reframe viral carousel tips.

**Железо:**

| Правило | Детали |
|---------|--------|
| Формат | Только **4:5 (1080×1350)** на все слайды — первый задаёт кроп |
| Длина | **6–10** слайдов (мы: 6). &lt;5 = «короткий пост»; &gt;10 = swipe fatigue |
| Slide 1 = 80% | Если хук не взял свайп — остальное никто не увидит |
| Текст на слайде | Хук короткий; на 2–3 и 5 можно **2–4 нормальных предложения** (не обрубок «заголовок + одна строка») |
| Плейсмент | Соседние кадры — **разные** схемы (`PLACEMENT_SCHEMAS.md`) |
| Фото | Коллажи **≥ на 2 кадрах** пакета |
| Шрифты | **Макс. 2** (display + body). Headline читается с вытянутой руки |
| Контраст | Тёмный/светлый блок под текстом; не pastel-on-pastel |
| CTA | **Только последний** слайд. На 1-м — запрещено |
| Логотип | Не жрёт &gt;15% кадра на хуке |
| Свайп-cue | Стрелка / «свайп →» **только на слайде 1** |
| Музыка | При публикации добавить трек → шанс попасть в Reels feed |
| Seam (SCRL) | Через каждый шов проходит объект/фото/линия — cliffhanger на свайп |
| Шов | Не режет лицо / главный объект посередине |

**Запрещено (это и был провал v1-демо):**

- Градиентные заглушки вместо фото места  
- Стена текста / 5 шрифтов / радуга акцентов  
- CTA и бренд-плашка на первом слайде  
- Разные aspect ratio внутри одной карусели  
- «Свайп» на каждом кадре  

**Эталон в репо:**

| Что | Путь |
|-----|------|
| **Боевая карусель (одна, готовая)** | `export/battle-zhivopisny/slide-01…06.jpg` + `demo-battle-zhivopisny.html` |
| Демо v2 | `export/{zhivopisny,aqueduct}/` |
| Авто-контраст | `contrast.py` — сэмпл пикселей под bbox, WCAG worst-case; **warm/gold всегда на тёмной плашке** |
| Боевой рендер | `python3 render_battle_zhivopisny.py` → пишет `contrast-audit.json` |

Нельзя постить слайд, если в audit есть `FAIL`.

## Копирайт (жёстко)

| ✓ | ✗ |
|---|---|
| **отрезок** | **кусок** (запрещено в Instagram-копирайте; assert в `layout_templates.py`) |
| Связный ответ человеку | Обрывки «КУДА ВСТАТЬ» + список мест без «для чего» |
| Заголовок с целью («Для лучшего фото») → тело-ответ | Вопрос-заголовок без ответа |
| Огромная цифра без ярлыка | Плашка «ВАУ-ФАКТ» на слайде (это внутренний термин) |
| Stroke/shadow текста | Тёмные rounded-плашки под каждой надписью |
| «Давайте разберёмся» / только вопрос | **«свайп» / «свайпни» / «за 20 секунд»** — запрещено |
| Факты из brief/источников | Выдуманные детали («почти никто не ходит» вместо «закрыта») |
| Разные кадры на 4–6 (+ иллюстрация ок) | Один и тот же crop на трёх слайдах подряд |
| Отступ текста от акцент-бара ≥ 24px | Текст впритык к зелёной полоске |
| CTA по центру, плотный gap к кнопке | CTA влево + огромная дыра над кнопкой |

Пример слайда «фото»:  
**Для лучшего фото** → «Встаньте на набережной или со стороны Серебряного Бора — лучше на закате.»

## Графика (жёстко)

| ✓ | ✗ |
|---|---|
| Готовый язык UI: map-pin, route mark (`icons.py`) | Самодельный прицел / crosshair / concentric target + оранжевая точка |
| Уголки кадра, акцент-бар, плашки | Рукодельные «радары» и doodle-кольца |
| **Реальная карта сервиса** (Carto + кольцо + пин) на слайде «на кольце» | Фейковый radar / doodle-кольцо «как карта» |
| Необычная иконка, которая говорит сама за себя | Кусок графики в тупой рамке + стрелка + подпись-пояснялка |
| Cover-crop 1080×1350 (равномерный scale) | Растягивание wide→portrait (`zoompan` по ультра-панораме без cover) |

**Паттерн поиска графики:** не первое попавшееся «поле сверху в карточке». Ищи необычный ракурс / изометрию / силуэт, который читается без UI-обвязки. Слово «ванты» и прочий инженерный жаргон — наружу не тащим.

Слайд 5 / «на кольце»: `bake_instagram_poi_map.py` → `assets/map-{landmarkId}.png`.  
Video-heavy (C) — только точки из `docs/instagram/VIDEO_POI_LIST.md`.

## Скелет карусели (5–7 слайдов, оптимум 6)

Формат ленты: **4:5 (1080×1350)**.

1. **HOOK** — провокация / вопрос (только слайд 1).
2. **МЕСТО** — что это, 1–2 предложения.
3. **ФОТО** — заголовок с целью + куда встать (человеческий ответ).
4. **ВАУ-ФАКТ** — одна цифра или twist + источник в brief.
5. **НА КОЛЬЦЕ** — «на Зелёном кольце» + отрезок мимо точки.
6. **CTA** — из пула ниже (ротация, не один шаблон).

## 10 layout-вариантов (единый стиль)

1. Full-bleed фото + хук снизу в плашке  
2. Фото → текст, плашка перетекает через шов SCRL на слайд 2  
3. Панорама на 2–3 слайда, текст только на шве  
4. Далеко / близко  
5. Крупная цифра на ~70% кадра  
6. Карта-кольцо + пин  
7. Человек на фоне + оверлей факта  
8. Коллаж 3 фото → «свайпни ещё»  
9. Тёмный слайд «только факт»  
10. Финал CTA: скрин UI green-route.ru + плашка

Миксовать layouts между постами; внутри одного поста — 1–2 приёма + финал CTA.

## CTA-пул (последний слайд)

Ротация. Всегда бренд **Зелёный Маршрут** + `green-route.ru`:

1. Соберите отрезок Зелёного кольца мимо этого места → green-route.ru  
2. Старт у МЦК/МЦД — и ты уже на маршруте. Зелёный Маршрут  
3. Не весь круг: выбери старт и финиш сам → green-route.ru  
4. Прокатись / пройди мимо [место] по готовому треку  
5. Семейный отрезок с туалетами рядом — на green-route.ru (Царицыно / Серебряный Бор)  
6. Сохрани пост и открой маршрут, когда будет час → green-route.ru  

## SCRL pipeline

Приложение: **[SCRL](https://scrl.com/)** (seamless Instagram carousel). Запасные: Panoslice, PanoCut.

1. Blank canvas → Frames = 5–7 → Ratio **4:5**.  
2. Класть фото/графику через швы; **не резать** лицо / арку / главный объект по линии слайда.  
3. Хук — только в кадре 1.  
4. Preview свайпа → Export «Save as Carousel».  
5. Проверить **порядок** (иногда reverse) → залить в Instagram.  
6. Опционально: один цветовой пресет на все слайды после export.

Демо-раскладки (HTML): `_previews/instagram-carousel/`.
