# 10 общих схем-блоков (глоссарий семей)

Формат кадра: **4:5 (1080×1350)**.  
Интерактивный просмотр: `_previews/instagram-carousel/demo-placement-schemas.html`.

**Главное для сборки поста:** варианты **по ролям карточек** — [`ROLE_LAYOUT_VARIANTS.md`](./ROLE_LAYOUT_VARIANTS.md)  
(`R1-A…D` … `R6-A…D`, демо `demo-role-layout-variants.html`).

S01–S10 ниже — общий словарь «семей» (низ-лево, коллаж-лента…).  
**Жёстко:** соседние слайды **не** берут одну и ту же семью.

| ID | Имя | Где текст | Когда |
|----|-----|-----------|--------|
| **S01** | Низ-лево | Стек снизу слева + акцент-бар | Хук / длинный абзац снизу |
| **S02** | Низ-право | Стек снизу справа | Ответ / эмоция, фото слева |
| **S03** | Верх-лево | Стек сверху слева | Маршрут на карте, небо чистое |
| **S04** | Верх-право | Стек сверху справа | Эмоция, акцент на левой половине кадра |
| **S05** | Середина-лево + цифра | Огромная цифра + тело слева | Взрывной факт |
| **S06** | Низ-центр | Текст по центру снизу | Мягкий финал до CTA |
| **S07** | Сплит верх/низ | Заголовок сверху, тело снизу | Об объекте с «воздухом» в середине |
| **S08** | Карточка-центр | Rounded card по центру | Зазывалочка / CTA |
| **S09** | Коллаж 2↑ + лента | Два кадра сверху, текст-лента снизу | Об объекте / эмоция |
| **S10** | Коллаж 2×2 + угол | Четыре тайла, текст в одном углу поверх | Эмоция / «много ракурсов» |

## Рекомендуемые миксы на 6 ролей

**Фото (Живописный эталон):**  
`1→S01 · 2→S09 · 3→S04 · 4→S05 · 5→S03 · 6→S08`

**Видео:**  
`1→S01 · 2→S07 · 3→S02 · 4→S05 · 5→S03 · 6→S08`

Соседи всегда разные; S09/S10 только на фото (коллаж).
