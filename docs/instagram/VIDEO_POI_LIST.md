# Достопримечательности с видео (для каруселей варианта C)

**Вариант C** (video-heavy) — только там, где есть нормальная съёмка: дрон / таймлапс / живой кадр места.  
Если видео нет — делаем JPEG (вариант A) или оживлённые stills (B), **не** подставляем чужой закат «на глаз».

Слайд **05** во всех motion-пачках = **статичная карта сервиса** (Carto + Зелёное кольцо + пин), не видео.

## Правило планирования

1. Brief места → колонка **video: yes/no/candidate**.  
2. `video: yes` → можно пачку **C_video_heavy**.  
3. `video: candidate` → не анонсировать C, пока клип не лежит в `assets/video/` (или не согласован сток).  
4. `video: no` → только A (JPEG) или B (alive stills).  
5. Слайд 5 всегда карта (`bake_instagram_poi_map.py`), даже в C.

## Как добавить новую точку в C

1. Положить клип(ы) в `_previews/instagram-carousel/assets/video/` (gitignore для чужих YT).  
2. Строка в этой таблице → **да**.  
3. Brief: `docs/instagram/briefs/{slug}.md` + пометка `motion: C`.  
4. Рендер: `python3 render_motion_demos.py` (или боевой скрипт поста).
