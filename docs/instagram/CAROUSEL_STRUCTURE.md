# Канон карусели Зелёный Маршрут (масштабируемая структура)

Документ для сборки **любого** поста про точку на Зелёном кольце.  
Эталон реализации: Живописный мост → `docs/instagram/stories/zhivopisny-flying-saucer.md` + `export/upload-zhivopisny/`.

---

## 1. Шесть ролей (не менять порядок)

| # | Роль | Задача кадра | Что можно на тексте |
|---|------|--------------|---------------------|
| **1** | Вовлекающий вопрос или утверждение | Остановить скролл | Короткий хук (вопрос **или** дерзкое утверждение). Без CTA, без «свайп» |
| **2** | Об объекте | Что это / где / когда | Имя + 2–4 предложения: задумка, год, контекст |
| **3** | Эмоциональная информация | Поворот / чувство | Не сухая хроника: закрыто / вау / «зачем едут» — живой абзац |
| **4** | Взрывной факт | Одна цифра или удар | Крупная цифра **без** ярлыка «ВАУ-ФАКТ» + сравнение с бытовым масштабом + 1 строка источника |
| **5** | Маршрут | Связка с продуктом | Реальная карта сервиса + объяснение Зелёного кольца новичку |
| **6** | Зазывалочка | CTA | Центр: оффер + кнопка green-route.ru |

**Плейсменты по ролям:** у каждой роли свой пул вариантов `R1-A…D` … `R6-A…D` — см. [`ROLE_LAYOUT_VARIANTS.md`](./ROLE_LAYOUT_VARIANTS.md).  
Не «один микс на весь пост из общих S01–S10», а **отдельный выбор раскладки на каждый номер карточки**.

**Правило соседства:** семьи раскладок на кадрах N и N+1 не совпадают (не два «низ-лево» подряд и т.п.).

## 2. Как писать пост (обязательный порядок работы)

1. **Опора для себя** (полстраницы прозы: начало → середина → конец). Не список слайдов.  
2. **Факты** из brief / Wikipedia / источников — без выдумок.  
3. **Разрезать** опору на 6 ролей таблицы выше.  
4. **Формулировки** на кадр: заголовок + тело (тело может быть 2–4 предложениям — не «односложных тупорылых»).  
5. **Плейсменты:** для роли 1 выбрать `R1-*`, для 2 — `R2-*`, …; проверить соседей.  
6. **Медиа:** либо пакет **фото** (коллажи ≥ на 2 кадрах), либо пакет **видео** (только клипы этой точки + карта на 05).  
7. Собрать папку `export/upload-{slug}/` (см. ниже).

Шаблон опоры: `docs/instagram/stories/_TEMPLATE.md`.  
Skill: `.cursor/skills/instagram-carousel-green-route/SKILL.md`.

## 3. Копирайт

| ✓ | ✗ |
|---|---|
| **отрезок** | **кусок** |
| 2–4 нормальных предложения на value-слайдах | Только заголовок + одно обрубленное предложение |
| Stroke / тонкий halo | Тёмные плашки под каждым абзацем |
| «Капсула закрыта» (факт) | «Почти никто не ходит» (выдумка) |
| Объяснить Зелёное кольцо на 05 | Предполагать, что все уже знают |
| | «свайп» / «свайпни» / «за 20 секунд» / «ванты» / «ВАУ-ФАКТ» на слайде |

**Объём текста:** на 2–3 и 5 можно чуть плотнее, чем «заголовок + одна строка». Хук (1) и факт (4) — короче; 4 держит крупную цифру.

## 4. Медиа-пакеты

### Фото (JPEG 1080×1350)

- Разные кадры / кропы; слайды 4–6 не клонировать один crop.  
- **Коллажи минимум на 2 кадрах** (часто 02 и 03, или 02 и 04).  
- Слайд 05 = `bake_instagram_poi_map.py` (Carto + кольцо + пин).  
- Анти-stretch: только равномерный cover-crop.

### Видео (MP4 ~4.5 с, без звука)

- Только съёмка **этой** точки (см. `VIDEO_POI_LIST.md`).  
- Слайд 05 = статичная карта (не чужой закат / не чужая река).  
- Плейсменты текста на оверлеях тоже миксовать (соседи ≠).

## 6. Папка загрузки поста

```
export/upload-{slug}/
  README.md           — как выложить
  POST.md             — опора + формулировки + caption
  photo/slide-01…06.jpg
  video/01…06.mp4     — опционально, если есть клипы
  layout-manifest.json
```

Instagram: залить **либо** photo, **либо** video-карусель (не мешать типы в одном посте без нужды). Caption — из `POST.md`.
