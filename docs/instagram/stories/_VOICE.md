# Голос хука (Instagram ЗКМ)

Эталон, который задал владелец: не музейная подпись, а **картинка + твист**.  
Дальше вся история **раскручивает ту же шутку**, а не сменяет тему на энциклопедию.

## Формула кадра 1

1. Сначала видишь одно (тарелка / камень / старинный кремль / торт / «Рим»).  
2. Сразу ломаешь это второй фразой (мост / дерево / 2007 / выпечка / водопровод).  
3. Без пояснялки «это архитектура». Если после хука хочется спросить «и что?» — хук мёртвый.

| Плохо | Хорошо |
|-------|--------|
| Самая высокая штука в Европе стоит в парке | Самая высокая башня в Европе стоит в Москве |
| Дворец выглядит каменным. Он деревянный | Дерево, которое замаскировали под камень |
| В Москве до сих пор крутят паровоз руками | В Москве до сих пор паровозы двигают люди! Куда смотрит Собянин? |
| Сказочный кремль. Ему нет и тридцати лет | Сказочный старинный кремль? Ему нет и тридцати лет! |
| Храм, который выглядит как торт — это архитектура | Выглядит аппетитно — здание, похожее на выпечку |
| Эталон | Что это за мост с летающей тарелкой? |

Провокация / «сенсация» ок, если факт потом держится. Шутка про Собянина — тон, не новость.

## Раскрутка (кадры 2–4)

Хук обещал тему — её и развивай:

- тарелка → капсула / ресторан / закрыта / 105 м  
- выпечка → ярусы как коржи, белый камень как глазурь, красный кирпич как корж  
- люди двигают паровоз → поворотный круг руками, не толкают состав по рельсам  
- «старинный кремль?» → 1998–2007, а настоящий XVII век рядом  
- дерево под камень → дворец для приёмов, не жильё  

Кадр 4 — удар по той же линии (цифра или год), не новый сюжет.

## Запрещено в хуке

- Канцелярит: «объект культурного наследия», «ансамбль», «расположен»  
- Два факта без картинки  
- Объяснить шутку в той же строке
