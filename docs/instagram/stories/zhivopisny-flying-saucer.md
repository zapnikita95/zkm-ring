# История поста: «Летающая тарелка»

**Место:** Живописный мост  
**Продукт-крюк:** точка на Зелёном кольце → отрезок на green-route.ru  
**Запрещено в копирайте:** «кусок», ярлык «ВАУ-ФАКТ» на слайде

---

## Сторилайн (зачем свайпать)

Не «вот мост и цифры». История про странный объект, который все фотографируют, но мало кто понимает.

| Слайд | Роль | Смысл |
|-------|------|--------|
| 01 | Крючок-вопрос | Что это за мост с летающей тарелкой? |
| 02 | Ответ | Живописный. Капсула — не декор: её задумывали как ресторан в воздухе. |
| 03 | Поворот | Внутрь почти не ходят. Снаружи снимают все — одна из самых узнаваемых точек Москвы. |
| 04 | Масштаб | **105** метров арки (гигантский шрифт, без ярлыка). Цифры ниже с воздухом. |
| 05 | Ты здесь | На Зелёном кольце проезжаешь мимо. Для кадра — набережная / Серебряный Бор на закате. |
| 06 | CTA | Соберите отрезок мимо моста → green-route.ru |

**Логлайн одной фразой:**  
«Над Москвой-рекой висит летающая тарелка — это не рендер, а Живописный мост; мимо него можно проехать свой отрезок Зелёного кольца.»

## Копирайт на слайдах (канон для всех 5 вариантов)

1. **Что это за мост с летающей тарелкой?**  
   Свайпни — разберёмся за 20 секунд.

2. **Живописный мост.**  
   Капсула под красной аркой — не шутка. Её задумывали как ресторан в воздухе. Открыт в 2007.

3. **Внутрь почти никто не ходит.**  
   Зато снаружи снимают все. Туристы едут сюда именно за кадром с «тарелкой».

4. **105**  
   метров арки  
   72 ванты · пролёт 409,5 м  
   Источник: Wikipedia «Живописный мост»

5. **На Зелёном кольце**  
   Проезжаешь мимо — и вот она. Для лучшего фото встаньте на набережной или со стороны Серебряного Бора на закате.

6. **Зелёный Маршрут**  
   Соберите отрезок Зелёного кольца мимо этого моста  
   green-route.ru

## 5 визуальных вариантов (выбор шаблона)

| ID | Идея размещения | Чем отличается |
|----|-----------------|----------------|
| A | Bottom-left stack + зелёный акцент-бар | Классика, воздух между строками |
| B | Top-right / bottom-left чередование | Текст прыгает по углам |
| C | Гигантская цифра по центру (слайд 4) | Максимальный вау без ярлыка |
| D | Тонкая рамка вокруг текстового блока (без заливки) | «Видоискатель» вокруг смысла |
| E | Split: крупное слева / подпись справа-снизу | Редакционный разнос |

Правила для всех:
- без тёмных плашек под текстом;
- без слова «ВАУ-ФАКТ» на картинке;
- вертикальный gap между блоками ≥ 28–48 px;
- только «отрезок».
