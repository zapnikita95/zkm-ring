# Варианты размещения по ролям карточек

У карусели **6 ролей**. У **каждой роли** — свой пул раскладок текста/инфографики.  
Собирая пост, для слайда 1 выбираешь один из вариантов **R1-***, для слайда 2 — из **R2-*** и т.д.

**Правило соседства:** схема на кадре N и N+1 не должна совпадать по «семье» (низ-лево / верх-право / коллаж-лента / центр-карточка…).  
Глобальные блоки S01–S10: `PLACEMENT_SCHEMAS.md`.  
Превью: `_previews/instagram-carousel/demo-role-layout-variants.html`  
Живые JPEG (Живописный): `export/role-layout-variants/`.

## Как собрать микс на пост

1. Для роли 1 выбери `R1-*`, для 2 — `R2-*`, …  
2. Проверь семьи соседей (не два «низ-лево» подряд).  
3. Запиши микс в story/POST, например:  
   `1→R1-B · 2→R2-A · 3→R3-A · 4→R4-A · 5→R5-A · 6→R6-A`

Эталон Живописный (текущий upload):  
`R1-A · R2-A · R3-A · R4-A · R5-A · R6-A`
