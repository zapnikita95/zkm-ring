# Варианты размещения по ролям карточек

У карусели **6 ролей**. У **каждой роли** — свой пул раскладок текста/инфографики.  
Собирая пост, для слайда 1 выбираешь один из вариантов **R1-***, для слайда 2 — из **R2-*** и т.д.

**Правило соседства (жёсткое):** у кадров N и N+1 **разная вертикальная зона** текста — `top` / `mid` / `bottom`.  
Нельзя два раза подряд класть основной стек внизу (или два раза сверху).  
Семья (лево/право/центр) — мягкий критерий: тоже лучше менять.

Код проверки / автоподбор: `_previews/instagram-carousel/role_layout_zones.py`  
Глобальные блоки S01–S10: `PLACEMENT_SCHEMAS.md`.  
Превью: `_previews/instagram-carousel/demo-role-layout-variants.html`  
Живые JPEG (Живописный): `export/role-layout-variants/`.

## Как собрать микс на пост

1. Выбери R1 исходя из кадра (куда «смотрит» фото).  
2. Для R2 и дальше — **сначала зона**, потом семья: после `bottom` только `top`/`mid`.  
3. Проверь: `python3 role_layout_zones.py` или `assert_mix([...])`.  
4. Запиши микс в story/POST.

### Эталон Живописный (photo)

`R1-A · R2-D · R3-B · R4-A · R5-A · R6-B`  
зоны: bottom → top → bottom → mid → top → bottom

### Видео-микс

`R1-A · R2-C · R3-B · R4-A · R5-A · R6-B`  
зоны: bottom → mid → bottom → mid → top → bottom

```bash
cd _previews/instagram-carousel
python3 -c "from role_layout_zones import pick_compatible; print(' · '.join(pick_compatible('R1-A')))"
```
