## Против часовой

Тот же список **в обратном порядке** (`orderCcw`).

Пример от **Парк Фили** (~17 км):

| Направление | Ориентиры на куске |
|---|---|
| По часовой | Фили → Крылатское → Сетунь → Хорошёво → Живописный → Бездонное → Строгино… |
| Против часовой | Фили → Воробьёвы → Смотровая → МГУ → Ладошки… |
