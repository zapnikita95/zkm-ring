# Telegram-бот «Зелёный Маршрут»

Быстрый вход: геолокация → отрезок на готовой линии → **Яндекс.Карты / Навигатор**.

Без регистрации. Без спортивного шума. Приложение — для карты и истории; бот — чтобы за 2–3 шага выйти на линию.

## Запуск

```bash
# токен: secrets/telegram-bot.env  (BOT_TOKEN=...)
cd bot
npm i
npm start
```

## Команды

| | |
|--|--|
| `/start` | Инструкция, выбор трека, кнопка гео |
| геолокация / `/near` | Ближайшая точка + отрезки 5/8/12/15 км |
| `/km 12` · `/time 60` | Сразу нарезать отрезок |
| `/tracks` | ЗКМ + Подмосковье |
| `/popular` | Вечер / час / выходной / короткий |
| `/bike` · `/walk` | Режим |

В пользовательских текстах пишем **«отрезок»**, не «кусок».
