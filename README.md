# Зелёный Маршрут

Android / PWA-приложение для своего куска Зелёного кольца Москвы.

## Android APK

1. Запустите API на Mac (телефон и Mac в одной Wi‑Fi / раздаче):

```bash
cd server && npm start
# слушает 0.0.0.0:8787
```

2. Соберите веб с адресом вашего Mac и APK:

```bash
export VITE_API_BASE="http://$(ipconfig getifaddr en0):8787"
npm run build
npx cap sync android
export ANDROID_HOME="$HOME/Library/Android/sdk"
cd android && ./gradlew assembleDebug
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`  
Также копируется в корень: `ZelenyMarshrut-debug.apk`

## Возможности

- Интро, дизайн «Зелёный Маршрут», иконка велик + пешеход
- Вело / пешком, направление, км или оценка времени
- GPS → ближайшая точка кольца (нужны разрешения)
- Навигация в приложении или кусками в Яндекс.Картах
- Учёт фактического времени в пути (без лимита)
- Регистрация логин/пароль (без почты), антиспам по IP
- Ачивки: км, время, точки, 3 парка / 3 озера и др. в профиле

## Правила логина

- Логин: 3–32, латиница/цифры/`_`
- Пароль: 8–72, буква + цифра
- Регистрация: ≤5 / час с IP; вход: ≤20 / 15 мин с IP
